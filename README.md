# SwiftBite: Analisis Performa Layanan Pesan Antar Makanan
Capstone Bootcamp Data Analyst. Analisis pesanan, pembayaran, pembatalan, keterlambatan pengiriman, dan sentimen ulasan pelanggan.

**Tools:** Python, pandas, Jupyter Notebook

## Temuan Utama
- Late delivery rate sebesar 31,2%, tertinggi di zona West (47,2%)
- Cancellation rate naik dari 9,8% menjadi 14,7% pada Q1
- Cakupan ulasan hanya 57,3% dari seluruh pesanan

## Rekomendasi
- Menyelidiki pembayaran yang gagal
- Memperbaiki pengiriman di zona West
- Menindaklanjuti pesanan yang terlambat
